Pattern syntax
  • Globs are case-insensitive: * any run of characters inside a name, ? one character, ** any number of directories, {a,b} alternatives, [abc] a character set.
  • No / in the pattern: it matches a file or directory name at any depth, for example *.spec.ts or __fixtures__.
  • With a /: it is matched against the full path from the repository root, for example src/**/*_test.go or tests/e2e/**. A trailing / means everything under that directory.
  • Regular expressions are written as /pattern/flags, for example /\.(test|spec)\.m?js$/i, and are tested against the full path. A slash-wrapped pattern with no flags and no regex syntax (/build/) is read as an anchored folder glob.
